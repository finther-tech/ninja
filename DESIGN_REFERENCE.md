## Design Do's and Don'ts

### ✅ DO
- Use purple gradient for key headings and CTAs
- Add subtle purple glow on hover
- Use cyan accent for AI/tech related content
- Keep animations smooth (300-600ms)
- Maintain strong contrast in both themes
- Use glassmorphism for header/overlays
- Add grid pattern to hero backgrounds
- Keep card borders subtle

### ❌ DON'T
- Overuse gradient text (reserve for emphasis)
- Make animations too fast or jarring
- Use pure black backgrounds (use near-black with purple tint)
- Forget hover states on interactive elements
- Overdo the purple glow (keep it subtle)
- Use too many colors (stick to purple + cyan accent)
- Make text too small on mobile
- Skip the theme toggle
